# SM Clipboard Manager

A clipboard history manager widget for Odoo systray.

## Features

- **Automatic History**: Saves copied text automatically
- **Pin Items**: Pin important items for quick access
- **Search**: Search through clipboard history
- **One-Click Copy**: Click any item to copy to clipboard
- **Clear History**: Clear all non-pinned items
- **Persistent Storage**: History saved in localStorage
- **Maximum 50 Items**: Automatic cleanup of old items
- **Keyboard Shortcut**: Ctrl+Shift+V to access

## Installation

1. Download the module
2. Place it in your Odoo addons folder
3. Update the apps list
4. Install "SM Clipboard Manager"

## Usage

1. Click the clipboard icon in the systray
2. Copy any text in Odoo - it's automatically saved
3. Click any history item to copy it again
4. Use the pin icon to keep important items
5. Search to find specific items

## Compatibility

- Odoo 16.0
- Odoo 17.0
- Odoo 18.0
